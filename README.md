# HAMSAN — 40개의 새로운 시선

함께가는산악회 현수막 디자인 추가 40안과 비교 갤러리.

- **A01–A30:** 함께가는산악회 30안
- **B01–B10:** 함산 10안
- **확정 카피:** 함께 가는 길, 함께 오르는 산
- **설립 표기:** SINCE 2021
- ‘시산제’ 문구 제외
- 이전 20안은 원본이 제공되지 않아 이 저장소에 포함하지 않았습니다.

## 보기

[GitHub Pages 갤러리](https://gc00online.github.io/hamsan-design-gallery/)

이름과 스타일별 필터, 확대 보기, 브라우저에 관심 시안 저장, 최대 3개 시안 비교, 개별 PNG 및 전체 ZIP 다운로드를 제공합니다. 확대 보기에서 좌우 화살표로 시안을 이동할 수 있습니다. `#A01`처럼 주소 끝에 번호를 붙여 개별 시안을 공유할 수 있습니다.

## 파일

- `assets/full/` — 생성 원본 PNG 40개, 약 3:1 가로형, 2171–2172 × 724px
- `assets/thumbs/` — 갤러리용 경량 WebP 40개
- `hamsan-40-designs.zip` — PNG 40개와 안내문
- `designs.json` — 시안 번호, 이름, 설명, 분류
- `prompts.json` — 제작 공통 지침 및 40개 개별 아트 디렉션. built-in image_gen 사용.
- `manifest.json` — 파일별 실제 크기와 SHA-256

디자인 방향 검토용 AI 생성 이미지입니다. 실제 현수막 인쇄용 벡터 원본이나 CMYK 인쇄 파일은 아니며, 선택 후 실제 규격과 글자를 정리합니다. A07은 문구의 ‘오르는’을 명확한 산세리프로 수정했습니다.

## 검증

40개 PNG의 열기·비율·중복 여부 및 ZIP 무결성을 검사했습니다. 한글과 설립 연도는 OCR와 육안으로 확인했습니다. Chrome에서 데스크톱 1440px, 모바일 390px·320px 레이아웃, 필터, 저장 유지, 비교 3개 제한, 키보드 이동, PNG 다운로드를 확인했습니다.
